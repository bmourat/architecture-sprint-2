
# Задания 2,3,4

## Как запустить

Для запуска приложения с кластером mongodb и одним инстансом redis, 
в каталоге sharding-repl-cache запускаем команду:

```shell
docker compose up -d
```

Конфигурируем и заполняем mongodb данными

```shell
./scripts/init.sh
```
